# 鲸鱼娘精致版桌面分支

本分支基于上游 `v0.4.4`，生产运行只加载鲸鱼娘精致版。其他内置素材仍留在 Git 历史与开发目录中，打包白名单仅包含精致版与状态装饰；用户自行安装的其他素材不会被删除。

## 使用

所有布局、动画和桌面显示控件都在「设置 → 宠物」。独立宠物没有常驻工具条。支持大小、字号、隐藏/召唤、拖动、位置记忆、归位、抚摸、喂食、改名、好感度、气泡、状态装饰和点击会话气泡回到 DSH。

主窗口隐藏或最小化后独立宠物继续显示；退出整个 DSH 时关闭。拖动按可见形象定位，不再受透明窗口外框及任务栏工作区边距限制。跨屏与负坐标受支持；启动或显示器变化时只纠正完全无法触及的形象。

| 活动 | 精致版动作 |
| --- | --- |
| 空闲、主动停止 | 站立、眨眼及合手闭眼序列 |
| 模型思考、工具返回后继续思考 | 向右跑步 |
| 写文件、编辑文件 | 向右跑步 |
| 命令、Shell、终端工具 | 站立合手 |
| 回复文字 | 托腮、歪头 |
| 等待、正常完成、失败 | 保留原等待、跳跃、低头动作 |

帧率设置只影响向右跑步。Tick 使用当前会话底栏的 tok/s，来自 `decodeTokens / (decodeMs / 1000)`，按底栏相同规则舍入；每步结算后更新，不估算逐字生成速度。

```text
FPS = clamp(k × 底部 tok/s + b, 1, 60)
默认 k = 1/6，b = 6
54 tok/s → 15 FPS
264 tok/s → 50 FPS
```

`k` 与 `b` 可独立编辑和持久保存。`k` 为 0.0001–60，`b` 为 -60–60，正斜率在限幅区间内保持线性增长，限幅后不下降。没有底栏统计时使用备用 FPS。固定帧率及素材原速模式仍可选。

大小允许 32–1024 的整数；气泡字号倍率允许 0.5–2，步长 0.05。无效输入会解释对应字段范围并阻止提交；真实写入失败另行提示，草稿保留。

## 降低运行开销

- 精致版以外的形象不扫描、不实例化；不注册未使用的 Live2D、逐帧图片渲染器。
- 动画按素材下一帧的截止时间唤醒，空闲时不再每次屏幕刷新都执行回调。高速右跑仍用绘制同步刷新；非循环动作完成后停止调度。
- 合并重复状态请求，仅在会话 ID 或桌面配置改变时发送相应更新；相同快照不会重复渲染。
- 精致版闭眼出现次数减半，其他动作时长与右跑速度不受影响。

同一隔离 Electron 窗口各测 5 秒空闲动画，动画回调从 300 次降到 20 次，减少约 93%。这是调度回调计数，不是整机功耗、电池续航或瓦数测量。原功能所需的状态轮询、交互与任务反馈继续保留。

## 安全处理

移除默认第三方安装统计调用；在本地与配对认证路径之前统一检查来源；写入要求 JSON 对象并校验类型与有限数值；媒体响应增加 `nosniff` 和受限 CSP。原有路径包含、资源白名单及大小限制继续保留。

独立窗口使用沙箱、上下文隔离、无 Node 权限及内存分区。禁止外部导航、新窗口、下载和权限请求。IPC 验证发送窗口及顶层 frame，仅提供固定宠物动作，不暴露通用 HTTP、文件或认证 cookie 接口。

审查范围是该插件及新增桌面桥接，不覆盖整个 DSH 和其他插件。持久层仍沿用部分尽力保存行为，磁盘故障的事务式处理可继续改进。

## 构建与宿主接入

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm typecheck
pnpm test
pnpm build
pnpm build:local
```

`build:local` 生成宿主插件、DSH 模块加载器客户端及独立窗口 bundle。桌面主进程集成还需要 `desktop/patch-desktop.cjs`：

```sh
node desktop/patch-desktop.cjs path/to/original/app.asar path/to/new/app-patched.asar
```

补丁器只接受已审查的 DSH Desktop 0.2.0-rc.2 归档哈希及本分支前序本地补丁哈希，始终输出新归档。它同时修复该宿主在设置模块重复加载时找不到根 Include 的问题。其他 DSH 版本会拒绝应用，需要重新审查入口。官方自动更新可能覆盖本地集成。

安装前应完全退出 DSH，备份完整 DSH 数据目录及原 `app.asar`，构建并检查补丁，再替换插件与宿主归档。恢复时只恢复程序和插件文件，避免用旧数据备份覆盖后续会话。仓库不包含个人备份、安装收据、应用二进制或聊天数据。

## 验证

本机已验证源代码回归、真实 Host 配置提交与重启持久化、独立 Electron 沙箱与 IPC 拒绝、主窗口隐藏后继续动画、四边拖动与位置恢复、尺寸变化、安装回退和归档完整性。桌面安装包测试时 441 项通过、1 项因缺少开发素材跳过。独立 SDK 类型检查也通过。

后续优先改进：用正式宿主窗口接口替代归档补丁；将状态轮询迁移为有序事件推送；增加低电量时可选的帧率上限和可视化动作预览。
