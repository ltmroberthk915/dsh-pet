# 鲸鱼娘精致版桌面分支

本分支基于上游 `v0.4.4`，生产运行只加载鲸鱼娘精致版。其他内置素材仍留在 Git 历史与开发目录中，打包白名单仅包含精致版与状态装饰；用户自行安装的其他素材不会被删除。

## 使用

所有布局、动画和桌面显示控件都在「设置 → 宠物」。独立宠物没有常驻工具条。支持大小、字号、隐藏/召唤、拖动、位置记忆、归位、抚摸、喂食、改名、好感度、气泡、状态装饰和点击会话气泡回到 DSH。

主窗口隐藏或最小化后独立宠物继续显示；退出整个 DSH 时关闭。拖动按可见形象定位，不再受透明窗口外框及任务栏工作区边距限制。跨屏与负坐标受支持；启动或显示器变化时只纠正完全无法触及的形象。

## 对话与配色

「设置 → 宠物 → 动画与桌面显示」中的多宠物模式默认关闭。关闭时仅显示一只 DS 原色宠物，动作、气泡、速度严格跟随主窗口当前对话；当前对话空闲时保持空闲，不借用后台对话的活动。

开启时，每个活跃的顶层对话各显示一只宠物。主窗口当前对话保持设置的完整大小，其余缩到 52.7%（原 62% 再乘 0.85），各自跟随所属对话的底栏 tok/s。小宠物禁止状态、碎碎念、用量和互动反馈气泡；双击小宠物切换到其对话后恢复完整大小和气泡。子代理不单独生成宠物。后台对话完成后保留小宠物等待查看。点开对话或双击小宠物，使其进入前台主视图即算查看，无须输入或发送消息；它暂时作为主宠物显示，切去其他对话时直接回收，不再缩小回来。所有已完成对话都查看后，只保留主对话的空闲宠物。最小化、后台轮询与失焦窗口不会确认查看；每次完成带有独立版本号，旧回执不能吞掉新一轮结果。会话被宿主释放或退出 DSH 时清理对应临时状态。

桌面窗口启用时，页面内的宠物组件整组卸载。窗口启动回执使用独立于状态轮询的序号，后续刷新不会丢弃有效回执；切换对话与最小化恢复也不会重新挂载第二份页面宠物。关闭桌面模式或窗口创建失败时，才恢复页面内显示。

| --- | --- |
| GPT | 豆沙绿 |

同一会话中途换模型不会换色，已分配颜色会持久保存。优先分配模型对应色；该色已占用时先用剩余基础色，五色用完后随机生成尽量相距较远的色相。最多保留最近 512 个会话的配色记录。

五套基础图集通过 `scripts/build-palettes.py` 对原素材精准换色生成，保留同一套帧坐标和透明轮廓，清理原素材绿边，不在运行时逐像素处理。需 Python、Pillow 和 NumPy；原始 WebP 保留不变。

**喂食次数、亲密度、小鱼干及互动冷却由所有宠物共同累计。** 各对话的完成奖励汇入同一份记录，按会话与轮次去重。切换对话、开关多宠物和重启不会拆分或重置这些数据；新颜色也不会新建养成记录。

| 活动 | 精致版动作 |
| --- | --- |
| 空闲、主动停止 | 站立、眨眼（闭眼概率减半） |
| 模型生成思考、回复正文（含代码和最终答案） | 向右跑步，按 tok/s 调速 |
| 生成写文件内容、修改、替换及补丁参数 | 向左跑步，按 tok/s 调速 |
| 生成其他工具调用参数 | 向右跑步，按 tok/s 调速 |
| 写入落盘、编辑执行、网页搜索、浏览器、Git、MCP、计划 | 向左跑步，素材原速 |

| 读取、文本搜索、找文件、列目录、记忆；消化工具返回结果 | 托腮、歪头 |
| 派发子任务 | 挥手一遍，然后回到执行动作 |
| 向用户提问 | 挥手一遍，然后等待 |
| 抚摸成功 | 挥手一遍；生成、完成和错误动画优先 |
| 等首 token、等待确认、阻塞 | 等待动作 |
| 本轮正常完成 | 跳跃 2.4 秒，然后空闲 |
| 工具错误或本轮失败、中断、达到输出上限 | 低头 2.4 秒，然后空闲 |

帧率设置影响正在生成模型内容的左右跑步。通过 `agent/assistant-stream` 的 reasoning/text/tool-call delta 区分生成用途，工具名称按调用 ID 记忆；空 delta、usage、命令日志和工具返回字数不作为生成依据。并行工具返回不抢占仍在生成的动画；finish/end/停止及时退出调速状态，旧 attempt 的迟到通知不覆盖新请求。工具真实执行保留素材原速。

Tick 使用所属会话底栏的 tok/s，来自 `decodeTokens / (decodeMs / 1000)`，按底栏相同规则舍入；每步结算后更新，不估算逐字生成速度。尚无统计时使用备用 FPS；左右跑共用已保存的 k、b，不重置用户参数。帧率变化不会把动画重新拉回第一帧。

鲸鱼娘使用独立 `voice.json`：保留 11 个状态场景、17 种工具、10 类碎碎念、3 种结果和 5 类互动，每类精选 3 句。原作者文案池保留作为回退。删除无依据的进度/成功承诺与重复填充文案，失败和等待用户回应时优先显示状态；保留 9 秒普通碎碎念、5 秒结果间隔和 8 秒有效期。

```text
FPS = clamp(k × 底部 tok/s + b, 1, 60)
默认 k = 1/6，b = 6
54 tok/s → 15 FPS
264 tok/s → 50 FPS
```

`k` 与 `b` 可独立编辑和持久保存。`k` 为 0.0001–60，`b` 为 -60–60，正斜率在限幅区间内保持线性增长，限幅后不下降。没有底栏统计时使用备用 FPS。固定帧率及素材原速模式仍可选。

大小允许 32–1024 的整数；气泡字号倍率允许 0.5–2，步长 0.05。无效输入会解释对应字段范围并阻止提交；真实写入失败另行提示，草稿保留。

## 降低运行开销

- 精致版以外的形象不扫描、不实例化；不注册未使用的 Live2D、逐帧图片渲染器。
- 动画按素材下一帧的截止时间唤醒，空闲时不再每次屏幕刷新都执行回调。高速生成跑步仍用绘制同步刷新；非循环动作完成后停止调度。
- 所有桌面宠物和主窗口共用一条状态轮询；各宠物窗口通过 IPC 接收更新，不各自发起网络轮询。相同快照不重复推送和渲染。
- 小宠物窗口使用更小的透明绘制区域；已查看并离开、且已完成的对话释放其窗口与渲染进程。待查看宠物在完成动画后转为空闲低频调度。
- 新建宠物、尺寸变化、拖动结束和显示器变化时按形象边界避让，主宠物保持位置；不添加逐帧物理循环。保留靠边及跨屏拖动。若显示器已无空位，选择重叠面积最小的位置。
- 精致版闭眼出现次数减半，其他动作时长与右跑速度不受影响。

同一隔离 Electron 窗口各测 5 秒空闲动画，动画回调基线为 300 次，优化后多次测得 14–22 次。这是调度回调计数，不是整机功耗、电池续航或瓦数测量。多窗口会增加渲染进程和显存开销；单宠物模式资源占用更低。

## 安全处理

移除默认第三方安装统计调用；在本地与配对认证路径之前统一检查来源；写入要求 JSON 对象并校验类型与有限数值；媒体响应增加 `nosniff` 和受限 CSP。原有路径包含、资源白名单及大小限制继续保留。

独立窗口使用沙箱、上下文隔离、无 Node 权限及内存分区。禁止外部导航、新窗口、下载和权限请求。IPC 验证发送窗口及顶层 frame，仅提供固定宠物动作，不暴露通用 HTTP、文件或认证 cookie 接口。

审查范围是该插件及新增桌面桥接，不覆盖整个 DSH 和其他插件。持久层仍沿用部分尽力保存行为，磁盘故障的事务式处理可继续改进。

## 构建与宿主接入

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm typecheck
pnpm test
pnpm build
pnpm build:local
```

`build:local` 生成宿主插件、DSH 模块加载器客户端及独立窗口 bundle。桌面主进程集成还需要 `desktop/patch-desktop.cjs`：

```sh
node desktop/patch-desktop.cjs path/to/original/app.asar path/to/new/app-patched.asar
```

补丁器只接受已审查的 DSH Desktop 0.2.0-rc.2 归档哈希及本分支前序本地补丁哈希，始终输出新归档。它同时修复该宿主在设置模块重复加载时找不到根 Include 的问题。其他 DSH 版本会拒绝应用，需要重新审查入口。官方自动更新可能覆盖本地集成。

安装前应完全退出 DSH，备份完整 DSH 数据目录及原 `app.asar`，构建并检查补丁，再替换插件与宿主归档。恢复时只恢复程序和插件文件，避免用旧数据备份覆盖后续会话。仓库不包含个人备份、安装收据、应用二进制或聊天数据。

## 验证

本机已验证源代码回归、真实 Host 配置提交与重启持久化、独立 Electron 沙箱与 IPC 拒绝、主窗口隐藏后继续动画、四边拖动与位置恢复、尺寸变化、安装回退和归档完整性。源码回归 571 项通过、2 项跳过；另排除本分支不打包的 Doro、Jyn 素材套件及受 Windows 符号链接权限限制的 asset-security、Live2D 套件和单项路径测试。SDK 类型检查通过。新增客户端回归覆盖延迟窗口回执、恢复可见性、会话组件重建及创建失败后重试，旧版在其中两项可稳定复现重复显示。

独立 Electron 测试 48 项通过，包括五窗口各自速度、缩放、五色图集加载、小宠物禁气泡、主对话切换竞争、新增与拖动避让、完成待查看、查看后离开回收、共享喂食与养成数据及共用轮询。真实 Host 设置沙箱 10 项通过。

后续优先改进：用正式宿主窗口接口替代归档补丁；将状态轮询迁移为有序事件推送；增加低电量时可选的帧率上限和可视化动作预览。
