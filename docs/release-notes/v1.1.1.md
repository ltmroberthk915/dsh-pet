# 多形象会话桌宠 v1.1.1

本次将鲸鱼娘稳定性修复、MIKU 会话版、商务小蓝鲸和 Windows 桌面补丁工具统一发布。

- “读取任务输出”（包括等待 `pwsh-8`）使用托腮动作，工具日志不会被算作模型生成。
- 五色鲸鱼娘统一直立高度并固定站立腿部；保留跑步、屈膝跳跃、低头及尾部动作。
- MIKU 保留原作者 v0.4.4 玩法，补齐九种会话动作、左右跑步摆臂与五套配色；新增现代商务小蓝鲸。
- Windows 安装工具支持检查、首次安装、旧补丁升级、重复安装和回滚，优先使用宿主自带 Node，支持中文及自定义路径。
- 安装前检查实际宿主 SHA256 和进程状态，自动备份 `app.asar`；不修改 `.dsh`、会话、账户、配置或亲密度。

## 下载与安装

主包为 `dsh-session-pet.tgz`，市场固定下载地址保持不变。`dsh-pet-desktop-1.1.1.zip` 为同版本小体积桌面安装工具附件，使用前先安装主插件。校验值见 `SHA256SUMS`。

独立桌面窗口还需在正常退出 DSH 后，运行附件或插件包中的 `desktop/Install-Desktop.ps1 -Mode Apply`。建议先用 `-Mode Check` 确认状态。详细步骤与回滚见 [Windows 安装说明](https://github.com/ltmroberthk915/dsh-pet/blob/v1.1.1/docs/install-desktop-windows.md)。

兼容范围为经校验的 DSH Desktop 0.2.0-rc.2 归档；未知构建会停止并显示 SHA256。新电脑尚未现场安装，需以该机检查结果为准。
