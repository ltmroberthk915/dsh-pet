# 1.5.1 · 宠物看板：「命名」换成「保持对话专宠」

- **宠物右键看板的动作行改为「补充能量 / 保持对话专宠 / 隐藏」（有玩法的宠物再加「玩法」）**。原来的「命名」输入框整条移除：改名不再是看板动作，名字仍按宠物定义显示，改名的宿主接口 `POST /api/pet/set-name` 与 `pet.json` 里的 `names` 数据完全不变，已有改名不会丢失。
- **看板里的「保持对话专宠」与侧栏会话 `...` 菜单的同一项是同一个宿主开关**（`POST /api/pet/session-keep`，持久化到 `pet.json` 的 `keptSessions`）。保持后，这条会话完成、你离开它，宠物仍留在原地；按钮带 `aria-pressed` 与按下态描边，可再次点击取消。
- **点哪只宠物就保持哪条会话**：并排的多只宠物各自保持自己所代表的会话，而不是当前主窗口的会话；桌面独立窗口与内嵌宠物行为一致（桌面桥的动作白名单同步改为 `session-keep`，`rename` 项移除）。
- **没有任何会话可保持时不显示这个按钮**：新会话界面（还没会话）与子代理会话都不显示。子代理宿主的写接口会直接拒绝（`subagent-session-not-keepable`），因为子代理宠物在服务端永远走原显示/隐藏规则，保持标记对它没有意义——状态快照新增 `keepable` 字段（按会话、随 `companions` 逐条下发），浏览器据此隐藏按钮，而不是给一个点了会失败的入口。
- 文案统一为「保持对话专宠 / 取消对话专宠」，与侧栏菜单行一致；设置页里「可在宠物悬浮面板改名」的说明同步改掉。
- **声音包 `voice.json` 的 `panel` 契约变更**：动作白名单与标签槽位由 `feed/rename/hide` + `confirm` 改为 `feed/keep/hide`（`contracts/voice-pack-v1.schema.json` 与校验器同步）。旧声音包里残留的 `rename`/`confirm` 会被静默忽略（不再报错），不会让宠物加载失败；商务小蓝鲸自带的声音包已改成「保持对话专宠」。
- 看板动作按钮改为可换行、不折行文字，中文长按钮不会把一行挤变形。
