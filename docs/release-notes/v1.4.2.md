# 1.4.2 · 启动提速与关闭后释放资源

- 保存运行库校验记录。文件身份、大小、修改时间和变更时间均未变化时，复用已验证的 SHA256，避免每次启动重复读取整套 Electron 运行库及缓存副本。首次准备、文件更新和索引丢失仍执行完整校验；缓存内容变化、路径重定向和引导脚本损坏仍会被检查。
- 启动工作延后最多约 1 秒，让宿主先完成自身初始化；主界面连接后可立即开始。关闭开关会取消排队的启动，准备过程中关闭再开启也会启动新的有效请求。
- 关闭桌面模式时结束独立进程。仅隐藏宠物时，保留约 5 秒宽限期，随后释放独立进程；再次开启时重新启动。
- 保留启动失败、进程退出和心跳中断后的自动恢复，以及“重试独立窗口”和“宠物窗口归位”。
- 新增运行库缓存、损坏检测、启动取消和重新开启的回归测试，并接入默认测试命令。

Windows 隔离实测：相同已准备运行库下，宠物窗口就绪从 2.01–2.48 秒降至 0.57–0.64 秒；未变化运行库的重复大文件哈希读取量降至 0。数字仅对应本机隔离测试，不代表完整 DSH 冷启动耗时。显示宠物时仍使用独立 Electron 进程。

此版本不修改 DSH 宿主归档或共享依赖回退目录。替换已加载插件后，正常完整退出并重开 DSH 以加载新进程代码。
