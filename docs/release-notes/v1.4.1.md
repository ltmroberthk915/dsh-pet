# 1.4.1 · 窗口恢复与自动保存

- 宠物点击直接从接收鼠标输入的独立窗口进程激活 DSH，避免经后台 Host 转发时丢失 Windows 前台激活许可；会话跳转仍经受认证的私有连接传递。
- 原生鼠标位置每 50ms 校正一次命中区域，避免最大化浏览器上鼠标移动转发中断后宠物持续穿透；4px 内的点击抖动不再移动原生窗口。
- 独立进程退出、启动超时或 20 秒心跳中断后自动恢复；连续失败按 1、2、4、8、16、30 秒退避，持续正常运行 30 秒后重置退避。等待旧进程退出后再启动，关闭开关或卸载时取消恢复。
- 渲染进程崩溃或持续无响应后自动重建宠物窗口，保留主宠物位置；短暂无响应后恢复的窗口继续使用。
- 宠物形象/显示设置及动画/桌面设置均自动保存，移除两处保存按钮。无效输入保留并提示修正；失败保留输入并重试；快速连续修改依次保存最新值。
- 保留“重试独立窗口”和“宠物窗口归位”手动按钮。

此更新不修改 DSH 宿主归档。升级已加载插件后需要重新加载宿主以启用新进程代码。
