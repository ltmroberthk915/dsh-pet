# v1.3.2

npm 分发包名为 `dsh-pet-copilot`。客户端模块、宿主清单与桌面载荷使用同一名称；原有宠物数据目录和设置命名空间保持不变。

修复新机安装后宠物设置页不能自动恢复、连接失败提示错误及发布包遗漏额外 JavaScript 文件的问题。

- 新增「悬停展开看板」开关，默认关闭；关闭时仍可右键打开补充能量、命名和隐藏面板，选择在重启后保留。
- 商务小蓝鲸在所有尺寸下统一缩小到 75%，同时缩小占位框和点击区域，主宠物与后台小宠物均适用。
- 左右跑动默认无 FPS 上限，可自行设置上限；其他动作可单独设置 FPS，关闭自定义时使用素材原速。所有形象规则一致。

- 服务连接持续重试，区分 401/403 授权失败，断线时禁用保存并保留草稿。
- 完整收录预编译运行文件，无消费者编译、安装钩子或 packageManager 依赖。
- 纠正安装和升级的重启说明；带包名的安装目标可识别重复安装。
- 保留 v1.3.1 的稳定原始动作、配色及 Windows 缓存路径修复。
- 分发包省略当前动画未引用的 640 张旧补间帧，保留全部 655 个运行时资源，缩减下载体积。

验证范围及分发条件见 `docs/fresh-install-v1.3.2.md`。公共 npm 发布需单独确认成功，不能以本地测试结果代替。
