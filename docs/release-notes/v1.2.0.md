# v1.2.0 · 安装插件，自动开启独立窗口

Windows 原生 DSH 安装并启用插件后，会自动准备并启动独立宠物窗口。新机器无需 Agent 打补丁、运行 PowerShell 或额外安装运行库，也无需退出或重启 DSH。

- 复用宿主现有 Electron 运行文件，在当前用户缓存中校验并复制；保持宿主 `app.asar` 原样。
- 窗口直接使用当前插件的渲染器和素材；更新插件即可更新三个形象，旧补丁窗口会停用。
- 设置页显示准备、运行、失败状态，提供重试与归位。主窗口最小化不影响宠物；停用插件或退出 DSH 时关闭窗口。
- 保留沙箱、上下文隔离、固定宠物操作和私有本地凭证，独立进程不继承提供商密钥。
- Git 分支自带编译产物，移除 `prepare`，不再要求消费者构建、配置提交 SHA 白名单或安装 pnpm shim。pnpm 版本声明仅供开发和 CI；Release 包不携带该声明。
- 文档明确原生 `desktop` profile、更新方式、`ambiguous-install` 等原始错误的处理。历史补丁工具继续保留，`Check` 增加内存干跑及产物哈希验证。

首次准备会使用数百 MiB 用户缓存。验证环境为 Windows、DSH Desktop 0.2.0-rc.2 / Electron 44；未在用户的另一台新电脑直接执行。其他系统和普通 Web Host 保留应用内宠物。自动窗口自身维持置顶；其他应用强制置顶时的前后顺序由系统决定。

验证：167 项相关回归、120 项原有原生窗口检查、22 项自动窗口与生命周期检查、17 项历史安装器检查及两项 TypeScript 检查通过。使用 DSH 内置 Node/pnpm 在空白 profile 安装预编译包成功，保持 `strictDepBuilds: true`，无需安装脚本、构建白名单或 pnpm shim；宿主归档哈希前后相同。

安装：

```sh
dsh plugin --profile desktop add https://github.com/ltmroberthk915/dsh-pet/releases/download/v1.2.0/dsh-session-pet.tgz
```

已有依赖应使用更新操作；固定旧版本 URL 时，改为上面的新版本 URL。完整说明见 [Windows 安装指南](https://github.com/ltmroberthk915/dsh-pet/blob/v1.2.0/docs/install-desktop-windows.md)。
