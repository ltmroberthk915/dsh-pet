# v1.3.0 · 鲸鱼游泳、动画补帧与稳定拖拽

小蓝鲸向右移动改为八帧游泳：尾鳍上下摆动，胸鳍配合划水，向左同步使用镜像游动。重新从完整画稿提取九组动作，修复旧图集切格截断头顶和尾鳍的问题，并缩小画面、增加四周留白。

三只角色的动画图像数翻倍：鲸鱼娘 126 → 252，MIKU 128 → 256，小蓝鲸 36 → 72，共 580 帧。新画稿使用内置 ImageGen 分批生成并人工复核，保留原始关键帧；采用整图等比缩放和位置校准。按每帧原有时长拆分，固定帧率与 tok/s 模式也计入补帧密度，保持原来的动作周期。

MIKU 在按下鼠标的当刻进入抓取状态，长按期间保持抓取动作，空闲导演和异步动作清理不能覆盖它。原生拖拽从最初的窗口位置与系统光标计算绝对位移，静止光标不再反复移动窗口。

继续提供安装插件自动开启的独立窗口，更新时携带完整渲染器和素材，无需在新电脑上让 Agent 打补丁。宿主原始 `app.asar` 不变。

安装包和源码：https://github.com/ltmroberthk915/dsh-pet/releases/tag/v1.3.0

```sh
dsh plugin --profile desktop add https://github.com/ltmroberthk915/dsh-pet/releases/download/v1.3.0/dsh-session-pet.tgz
```

生成来源、取舍和复核说明见 [动画补帧记录](../motion-v1.3.0.md)。
