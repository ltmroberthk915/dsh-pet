# dsh-pet-copilot v1.3.3

- 增加按 profile 执行的改名迁移器，备份后原子修改名称，保留配置、禁用状态、注释和后来保存的新设置；使用真实 DSH 合成验证。
- 保留上游主开关修复：停用插件不再永久写入隐藏意愿，重新启用恢复原状态。
- 保留独立动作速率、用户自设跑动上限、商务鲸鱼 0.75 底板与可关闭的悬停看板。
- 同名版本包、兼容文件名、迁移附件和 SHA256 校验文件统一分发；剔除开发源码、测试及未使用的插值帧。
- 安装说明提供桌面 CLI 明确路径，区分热加载与需要重启的情况，旧 ASAR 工具标为 legacy。

npm 先 next，成熟且通过严格验证后才推广 latest。默认非严格 pnpm 11.7.0 可能自动添加单版本例外；严格冷却未满足时，包名、精确版本和 npm tgz URL 均不能绕过。首次新包名可能暂时没有 latest，项目不修改用户全局策略。

check 可通过 DSH_PET_REGISTRY 查询镜像并输出来源；网络失败不当作未发布。promote 始终核对 npm 官方源的身份、时间和严格安装回执。市场收录、镜像同步及更长的用户冷却政策分别适用。

The package identity is dsh-pet-copilot. This release adds profile-scoped, backed-up configuration migration and preserves the upstream reversible master switch. Artifacts include canonical and identical legacy archives, migration launchers and checksums. First additions can hot-load; replacement or restart-required needs a restart. Strict release-age policies cannot be bypassed by version pins or npm tarball URLs. Checks can read a selected mirror, but promotion always revalidates official npm. Catalog inclusion is separate from publication.
