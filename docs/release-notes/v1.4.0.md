# v1.4.0 · 纯气泡模式与鼠标交互

在「设置 → 宠物 → 动画与桌面显示」开启「仅显示状态气泡（无宠物图）」，保存后仅显示可拖动的任务气泡。无任务消息时常驻「随时就绪」；执行命令、等待响应等状态继续使用所属会话的实际文案。纯气泡模式不挂载宠物图、动画渲染器或图片装饰，也不保留图片占位。关闭开关即可恢复所选形象，名字和养成记录保留。

左键单击宠物直接唤出 DSH 桌面窗口；后台小宠物同时打开所属会话。右键抚摸并展开或收起宠物看板，MIKU 的触摸区域交互也随右键触发。拖动后的松手不会误触发唤窗。纯气泡仍支持拖动、左键打开会话、右键看板、喂食、命名和隐藏。

鲸鱼娘、MIKU、商务小蓝鲸按实际素材的透明轮廓预计算命中包络，各动作使用覆盖该动作所有帧的稳定轮廓。待机点击面积相较原图片矩形分别减少约 52%、39%、65%，其他动作按自身轮廓切换。DOM 与原生窗口共享这份几何，透明区域可穿透；图片不执行运行时逐像素扫描。自定义素材继续使用自身的原交互区域。

修复切换形象或尺寸、合成离开事件之后，DOM 和原生光标状态不一致时沿用旧穿透状态的问题。新光标位置会重新同步原生命中，即使 DOM 的内外判断未变。

验证：565 项单元测试通过、1 项跳过，类型检查通过；新增 30 项原生交互检查和已有 140 项原生窗口检查全部通过，覆盖设置保存与重新挂载、持久化往返、状态文案、三套形象轮廓和鼠标穿透、左右键及拖动释放。安装包重新解包校验通过，包含 655 项实际使用的形象资源。

从本 Release 下载 `dsh-pet-copilot-1.4.0.tgz`，按 `SHA256SUMS.txt` 校验后，用 DSH 官方 CLI 安装到所需 profile。示例：

```powershell
& $dsh plugin --profile desktop add 'dsh-pet-copilot@file:C:/Downloads/dsh-pet-copilot-1.4.0.tgz'
```

`$dsh` 指向 DSH 安装目录中的 `resources/runtime/cli/bin/dsh.cmd`。2026-10-09 已将 npm 默认渠道 `latest` 推广到 1.4.0，`next` 也保持为 1.4.0。在「设置 → 插件 → 添加插件」输入 `dsh-pet-copilot` 即可使用默认发行版，也可明确填写 `dsh-pet-copilot@1.4.0`。官方 npm 源的全新安装、从 1.3.3 升级和重复安装已通过严格 24 小时冷却验证，没有发布年龄例外；[验收记录](../release-verification/v1.4.0-npm-latest.json)保留版本、校验值和结果。
